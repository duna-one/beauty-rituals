# Маленькие ритуалы

Персональная страница-подарок с описанием 12 средств для тела и волос.

[Открыть сайт](https://duna-one.github.io/beauty-rituals/) · [Репозиторий](https://github.com/duna-one/beauty-rituals)

Откройте `index.html` двойным кликом. CSS, JavaScript, пиктограммы и оформление находятся внутри этого файла; шрифты системные. Сборка и внешние библиотеки для сайта не нужны. Фотографии лежат в `images/`, источники указаны в `images/SOURCES.md`.

Основной сценарий — телефон. Нижняя плавающая навигация доступна во время чтения; полные INCI открываются через нативный `details`. Поддерживаются клавиатура и reduced motion. Без JavaScript тексты, составы и навигация работают, вместо фотографий остаются декоративные заглушки.

## Как поменять фотографию

1. Замените нужный JPG в `images/`, сохранив имя файла.
2. Если новый снимок уже содержит только товар, удалите у соответствующего `img` атрибуты `data-crop` и `data-mask` в `index.html`.
3. Откройте страницу заново. При отсутствии или ошибке изображения автоматически видна оформленная заглушка.

Для исходных фотографий Ozon `data-crop` задаёт видимый прямоугольник (x0,y0,x1,y1 от 0 до 1), а `data-mask` скрывает рекламные подписи средствами CSS. Исходные снимки сохранены без ретуши. Эти настройки не нужны для готовых отдельных фото продуктов.

## Публикация

GitHub Pages публикует корень ветки `main`. После изменения файлов достаточно сделать commit и push. Файл `.nojekyll` включает обычную статическую публикацию.

## Проверка

`tools/check.mjs` использует Playwright из bundled runtime Codex и установленный Chrome. Проверяет 1440, 768, 390 и 320 px, составы, отсутствие горизонтального скролла, загрузку фотографий и заглушки, режим reduced motion и доступность текста без JavaScript. Путь к Playwright и Chrome можно изменить в скрипте для другой машины.
